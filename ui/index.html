📝 Task Evaluation Specifications

Task 1

Summarization

Evaluation Dataset: assets/evaluation_dataset.json (5 held-out examples)
Input Format: Text prompt string (prompt)
Ground Truth / Reference: Concise reference summary string (reference_text)
Preprocessing & Isolation: Whitespace normalization and tokenization on a dedicated offline benchmark dataset isolated from runtime inference prompts.
Evaluation Data Type: Technical articles, clean energy reports, and research briefs
Why Data is Suitable: Evaluates text compression and key information retention across technical domain text.
Primary Metric: ROUGE-L (F1 score of Longest Common Subsequence)
Secondary Metric: Latency (ms per prompt inference)
Candidate Models: Primary: sshleifer/distilbart-cnn-12-6 | Fallback: t5-small
Configuration Decision: Benchmark results are used to establish the Primary/Fallback model configuration. The model with higher average ROUGE-L score designates the Primary model.
Task 2

Sentiment Analysis

Evaluation Dataset: assets/evaluation_dataset.json (5 held-out examples)
Input Format: Text review string (prompt)
Ground Truth / Reference: Categorical label string (positive, negative, neutral)
Preprocessing & Isolation: String cleaning and lowercase label matching on a dedicated offline benchmark dataset isolated from runtime inference prompts.
Evaluation Data Type: Customer reviews, product feedback, and service experience prompts
Why Data is Suitable: Evaluates classification accuracy across positive, negative, and neutral feedback.
Primary Metric: Accuracy (Exact match percentage against ground truth label)
Secondary Metric: Latency (ms per prompt inference)
Candidate Models: Primary: cardiffnlp/twitter-roberta-base-sentiment-latest | Fallback: distilbert-base-uncased-finetuned-sst-2-english
Configuration Decision: Benchmark results are used to establish the Primary/Fallback model configuration. The candidate achieving highest overall classification accuracy designates the Primary model.
Task 3

Translation

Evaluation Dataset: assets/evaluation_dataset.json (5 held-out examples)
Input Format: Multi-lingual translation prompt string (prompt)
Ground Truth / Reference: Human-translated reference sentence string (reference_text)
Preprocessing & Isolation: Tokenization and NLTK BLEU sentence smoothing on a dedicated offline benchmark dataset isolated from runtime inference prompts.
Evaluation Data Type: Multi-lingual translation prompts (English to French, Spanish, German, Hindi)
Why Data is Suitable: Evaluates translation fluency and n-gram precision across target languages.
Primary Metric: BLEU (Sentence-level n-gram precision with smoothing)
Secondary Metric: Latency (ms per prompt inference)
Candidate Models: Primary: t5-base | Fallback: t5-small
Configuration Decision: Benchmark results are used to establish the Primary/Fallback model configuration. The candidate yielding highest average BLEU score designates the Primary model.
